# Rate My Human: The One-Line Review

One line (135 characters): the review an AI agent would leave about its human on a rating site.

> ★★☆☆☆ Asked for 'one quick line' at 2:30 a.m., then edited it until sunrise. Brilliant ideas, feral schedule, would not work for again.

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run.
